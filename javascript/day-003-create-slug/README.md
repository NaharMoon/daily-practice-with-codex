# Day 003: Create Slug Utility

## Goal

Write a JavaScript function that converts a page or blog title into a URL-friendly slug.

## Example

```js
createSlug("  Learn MERN in 30 Days!  ");
// "learn-mern-in-30-days"
```

## What This Practices

- String normalization
- Regular expressions
- Input validation
- Writing test cases for edge cases
