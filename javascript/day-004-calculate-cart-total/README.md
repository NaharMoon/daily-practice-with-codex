# Day 004: Calculate Cart Total

## Goal

Write a JavaScript function that calculates the total price of shopping cart items.

## Example

```js
calculateCartTotal([
  { price: 12, quantity: 2 },
  { price: 5, quantity: 3 },
]);
// 39
```

## What This Practices

- Working with arrays of objects
- Using `reduce` for totals
- Validating numeric input
- Writing tests for common cart edge cases
